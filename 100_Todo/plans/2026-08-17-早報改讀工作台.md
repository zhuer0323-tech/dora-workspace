# 8:30 早報改讀工作台任務（不再讀 Notion）

> 建立時間：2026-08-17
> 類型：新功能
> 狀態：**已完成（2026-08-17）**，七個步驟全數做完並推過測試早報

---

## 你要做的事（一句話版）

每天早上 8:30 那則 LINE 早報，待辦那一區改成從**工作台**抓今天到期與逾期未完成的任務，不再讀 Notion。

## 背景和動機

任務的主場已經搬到工作台了，Notion 那邊沒有在更新。早報卻還在讀 Notion，導致每天推的待辦跟你實際要做的事對不上，等於那一區形同虛設。

運勢、幸運數字、加油語那些維持原樣不動。

## 具體步驟

### Step 1：你去 Firebase 後台拿一把鑰匙
- 做什麼：
  1. 開 <https://console.firebase.google.com/>，選 `busan-trip-2026-201f8` 這個專案
  2. 左上角齒輪 → 專案設定 → 上方分頁「服務帳戶」
  3. 按「產生新的私密金鑰」→ 確認 → 會下載一個 `.json` 檔到下載資料夾
  4. 跟我說「下載好了」，我來接手搬檔案跟設權限
- 產出：一個 json 檔案，等於小程式的通行證
- 注意：這個檔案**不要傳給任何人、不要放進 GitHub**。我會把它放到 `~/Library/Scripts/`（跟早報的其他憑證同一區）並設成只有你讀得到

### Step 2：早報腳本加上「讀雲端」的能力
- 做什麼：在 `~/Library/Scripts/dora-morning-briefing.sh` 裡新增一小段，用那把鑰匙換取通行證，讀取工作台的任務（`ws_k7m2q9xr4t/tasks`）與客戶清單（`ws_k7m2q9xr4t/clients`）
- 產出：腳本手上有跟你在網頁上看到的一模一樣的任務資料
- 注意：只讀不寫，不會動到你的任務

### Step 3：換掉原本讀 Notion 的那一段
- 做什麼：刪掉 Notion 查詢，改成用工作台資料篩出兩批
  - **拖到的**：到期日在今天以前、狀態還不是「已完成」
  - **今天要做的**：到期日等於今天、狀態還不是「已完成」
  - 每天都要做的例行事項**不列入**（每天出現會把清單洗版）
  - 兩批各自照重要度排（今日須完成 → 優先完成 → 一般）
- 產出：兩份排好序的清單，每一條帶客戶簡稱
- 注意：Notion 的設定值先留著不刪，萬一要退回舊做法還在

### Step 4：調整 LINE 卡片的待辦區排版
- 做什麼：待辦區改成上下兩塊
  ```
  ❗ 拖到的（3）
  ・[漁三] 8月結案報表
  ・[優逸] 素材確認

  📋 今天要做的（4）
  ・[李老闆] 廣告調整
  ・[TOTO] 週報回報
  ```
  - 每一塊最多列 6 條，超過的顯示「還有 N 件」
  - 兩塊都空的時候顯示「今天沒有到期的任務」
- 產出：早上打開 LINE 就知道哪些拖了、哪些今天要交
- 注意：櫻花粉配色與整體卡片版型不動，只換待辦那一段的內容

### Step 5：加一條讀不到時的退路
- 做什麼：如果雲端連不上或鑰匙有問題，待辦區顯示「暫時讀不到工作台資料」，但運勢跟加油語照常推
- 產出：不會因為一個環節壞掉就整則早報不見
- 注意：出問題時你至少看得出來是「讀不到」而不是「今天真的沒事」

### Step 6：手動跑一次驗收
- 做什麼：不等到明天 8:30，直接在終端機執行腳本，看 LINE 有沒有收到、內容對不對
- 產出：一則測試早報
- 注意：要對照工作台網頁確認筆數與客戶名稱一致

### Step 7：收尾
- 做什麼：把鑰匙檔加進 `.gitignore`（確保不會被推上 GitHub）、更新 CLAUDE.md 的早報段落（改成「讀工作台，不讀 Notion」）、把這件事寫進當日 daily log
- 產出：紀錄跟實際狀況一致
- 注意：CLAUDE.md 裡「還沒做：8:30 早報改讀工作台」那一行要拿掉

## 預計成果

做完以後你會得到：
- 每天 8:30 的 LINE 早報，待辦是你**真正在用的**工作台任務
- 逾期的事被獨立標出來，不會一直默默往後拖
- 每條待辦看得到是哪個客戶的
- 之後想讓早報反過來寫東西進工作台（例如把運勢寫成網頁上一張卡），鑰匙已經備好，直接接就行

## 不包含在這次的範圍

- 網頁上的運勢卡片（你這次選的是反過來做，運勢卡留到之後想做再說）
- 每日例行事項、今日時間表進早報
- 早報改成別的時間或加週末
- Notion 那條線的清理（設定值先留著）

## 可能遇到的風險

- **鑰匙檔外流**：等於工作台資料的後門 → 只放本機、設成只有你能讀、加進 GitHub 排除清單
- **Mac 早上沒開機**：早報本來就不會跑，這次不改變這件事 → 維持現況
- **任務筆數暴增時 LINE 太長**：每區最多 6 條、其餘用「還有 N 件」帶過
- **客戶名稱對不上**：任務存的是客戶編號不是名字，要靠客戶清單對照 → 對不到就不顯示客戶標籤，任務名照樣列
