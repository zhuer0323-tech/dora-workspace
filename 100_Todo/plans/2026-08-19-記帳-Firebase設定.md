## 為什麼要多這一步

記帳資料跟工作台放在同一個 Firebase 專案 `busan-trip-2026-201f8`，
但走**獨立節點** `mn_x3f9b6qz`，跟工作台的任務完全分開。
Firebase 預設「沒寫進規則的節點一律不給讀寫」，所以要新增一段規則放行。

規則一樣綁你的 Google 帳號，沒登入、或不是 `zhuer0323@gmail.com`，一筆都讀不到。

## 怎麼做

1. 開 <https://console.firebase.google.com/> → 進 `busan-trip-2026-201f8`
2. 左邊選 **Realtime Database** → 上面切到 **規則（Rules）** 分頁
3. 整段換成下面這份 → 按 **發布（Publish）**

```json
{
  "rules": {
    "busan2026": {
      ".read": true,
      ".write": true
    },
    "meetings": {
      ".read": true,
      ".write": true
    },
    "connieScripts": {
      ".read": true,
      ".write": true
    },
    "ws_k7m2q9xr4t": {
      ".read": "auth != null && auth.token.email === 'zhuer0323@gmail.com'",
      ".write": "auth != null && auth.token.email === 'zhuer0323@gmail.com'"
    },
    "hy_social_r7n3k8": {
      ".read": "auth != null && auth.token.email === 'zhuer0323@gmail.com'",
      ".write": "auth != null && auth.token.email === 'zhuer0323@gmail.com'"
    },
    "mn_x3f9b6qz": {
      ".read": "auth != null && auth.token.email === 'zhuer0323@gmail.com'",
      ".write": "auth != null && auth.token.email === 'zhuer0323@gmail.com'"
    }
  }
}
```

> 只有最後那段 `mn_x3f9b6qz` 是新的，前面五段是原本就有的，**不要刪**。

4. 打開 <https://zhuer0323-tech.github.io/dora-workspace/money/> → 按「用 Google 登入」
   → 右上角變綠點「已同步」就成功了

## 裝到手機桌面

- **iPhone**：用 Safari 開上面那個網址 → 下面的分享鈕 → 加入主畫面
- **Android**：用 Chrome 開 → 右上角三個點 → 安裝應用程式

## 出問題的時候

| 狀況 | 原因 | 怎麼辦 |
|:--|:--|:--|
| 右上角一直是「沒連上」 | 規則沒發布，或 `mn_x3f9b6qz` 打錯字 | 回第 3 步再貼一次 |
| 說沒有權限 | 登到別的 Google 帳號 | 設定 → 登出 → 用 zhuer0323@gmail.com 再登一次 |
| 手機沒訊號時記的帳不見了 | 不會不見 | 會先存在手機裡，右上角顯示「待補 N 筆」，連上網自動補寫 |
| 換手機看不到舊資料 | 要先登入 | 登入後會自動把雲端的抓下來 |
