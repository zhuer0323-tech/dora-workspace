# LINE 小秘書：在 LINE 打一句話就排進工作台

> 建立時間：2026-08-17
> 類型：新功能
> 狀態：**已完成（2026-08-17）**，接線生已上線並驗證過端到端流程

---

## 你要做的事（一句話版）

把現有的「Dora賺錢小能手」從只會推播的機器人，升級成聽得懂你打字的小秘書：你在 LINE 打「8/20 漁三 結案報表」，它就把這件事排進工作台，並回你一句確認。

## 背景和動機

任務的主場是工作台，但你不一定隨時在電腦前。想到一件事的當下最快的入口是 LINE，現在打過去卻沒有任何反應，等於白打。這次讓它接住。

這次**只做新增**。查詢、打勾完成、改內容都不做，等這條路走順再加。

## 具體步驟

### Step 1：把機器人從單向改成雙向（LINE 後台）
- 做什麼：
  1. 我用瀏覽器開 LINE Developers 後台，找到「Dora賺錢小能手」這個機器人
  2. 複製一組**驗證用的密碼**（用來確認訊息真的是 LINE 送來的，不是別人偽造）
  3. 之後 Step 5 部署好會拿到一個接收網址，填回這裡並開啟
  4. 把「自動回覆訊息」關掉（不然你打字它會先回罐頭訊息）
- 產出：機器人可以收訊息了
- 注意：你可能需要在畫面上點一次確認，或幫忙登入

### Step 2：建立接線生的骨架
- 做什麼：在工作區開一個新資料夾 `100_Todo/projects/line-secretary/`，放接線生的程式；用 Cloudflare 的免費空間跑
- 產出：一個 24 小時待命、有固定網址的接收站
- 注意：需要登入 Cloudflare 授權一次（我操作，你點同意）

### Step 3：只聽你一個人的話
- 做什麼：接線生收到訊息時先做兩道檢查——一是驗證這則訊息真的來自 LINE（用 Step 1 那組密碼），二是確認傳訊息的人是你本人（比對你的 LINE 使用者編號）。不是你的一律不理，也不回覆
- 產出：別人就算加了這個機器人也動不了你的任務
- 注意：這道檢查不能省，因為工作台裡有客戶名稱

### Step 4：看懂你打的那句話
- 做什麼：把一句話拆成三件事
  - **日期**：認得「8/20」「2026-08-20」「今天」「明天」「後天」「週五」「下週一」；沒寫就排今天，並在回覆裡註明「沒抓到日期，先排今天」
  - **客戶**：用工作台現有的客戶清單與關鍵字比對（跟你在網頁上打字時同一套規則）
  - **工作類型**：用設定頁那 10 種類型的關鍵字比對，同樣是同一套規則
  - 剩下的文字就是任務名稱
- 產出：一件已經分好客戶與類型的任務
- 注意：判斷規則是從工作台網頁**抄一份**過來的。日後在網頁改了分類規則，這邊要跟著改，兩邊不會自動同步——這件事要寫進 CLAUDE.md 的維護重點

### Step 5：寫進工作台
- 做什麼：把任務寫進工作台的雲端，欄位跟你在網頁上「快速記一筆」建出來的完全一致（重要度預設「今日須完成」、狀態「待開始」、來源標記成 LINE）
- 產出：打完字回工作台網頁重新整理就看得到
- 注意：寫入用的鑰匙跟早報是同一把（Firebase 服務帳號），放在 Cloudflare 的加密設定裡，不會進 GitHub

### Step 6：回你一句確認
- 做什麼：幾秒內回一則訊息，長這樣
  ```
  ✅ 已排入 8/20
  漁三 · 結案報表
  類型：結案報告
  ```
  認不出客戶時寫「客戶：未指定（之後在工作台補）」；完全存不進去時回「沒存成功，請稍後再試」
- 產出：你知道它有沒有收到、猜得對不對
- 注意：LINE 規定 10 秒內要回應，所以先回覆再做後續處理

### Step 7：實測與收尾
- 做什麼：
  1. 我從你的 LINE 實際傳三句測試（有日期的、沒日期的、認不出客戶的）
  2. 對照工作台網頁確認三筆都正確
  3. 寫進 CLAUDE.md（機器人現在是雙向、程式位置、鑰匙位置、分類規則要兩邊同步）
  4. 寫進今日 daily log 與記憶
- 產出：可以正式開始用
- 注意：測試建立的假任務測完要刪掉

## 預計成果

做完以後你會得到：
- 想到什麼事，打開 LINE 打一句話就排進工作台，不用開電腦
- 客戶與工作類型自動判斷好，跟你在網頁上打字的結果一致
- 回覆會告訴你它怎麼判斷的，猜錯當下就發現
- 早報隔天早上就會把它列進待辦（因為資料是同一份）

## 不包含在這次的範圍

- 在 LINE 裡查詢任務、打勾完成、修改內容
- 語音訊息、圖片、轉寄的訊息
- 多人使用（只認你一個人）
- 讓它「學」你的修正（網頁上的學習紀錄照舊，接線生只讀不寫）

## 可能遇到的風險

- **別人傳訊息給機器人**：只認你的使用者編號，其他人一律不理
- **鑰匙外流**：放在 Cloudflare 的加密設定裡，程式碼裡不出現，也不進 GitHub
- **分類規則兩邊不同步**：網頁改了規則，LINE 這邊還是舊的 → 寫進 CLAUDE.md 維護重點，改網頁時順手改
- **它猜錯日期或客戶**：回覆會顯示判斷結果，發現不對就到工作台改（這次不做在 LINE 修改）
- **Cloudflare 免費額度**：每天 10 萬次請求，你的用量差得很遠，不會踩到
