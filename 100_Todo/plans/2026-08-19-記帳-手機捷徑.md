# 在手機上一句話記帳（不用打開 App）

> 2026-08-19 上線。接線生已經架好也測過了，**剩下你在 iPhone 上建一個捷徑**，
> 大概五分鐘。建完就能在鎖定畫面或控制中心按一下，打一句話記完就走。

## 這是什麼

跟 LINE 小秘書同一隻程式（Cloudflare Workers），只是多開一條路 `/money`。

```
iPhone 捷徑 ──POST──> dora-line-secretary.workers.dev/money ──> 記帳的雲端節點
                        （驗一組只有你手機裡有的密碼）
```

好處是**完全不會跳出 App**，按一下、打字、結束。記完打開記帳 App 就看得到。

## 密碼在哪

`~/Library/Scripts/dora-money-token.txt`（權限 600）。

**這串不能貼進 repo**——dora-workspace 是公開倉庫，貼上去等於公告給全世界，
任何人都能往你的帳本亂寫。要換一組的話：

```bash
cd 100_Todo/projects/line-secretary
NEW=$(python3 -c "import secrets; print(secrets.token_urlsafe(32))")
printf '%s' "$NEW" | npx wrangler secret put MONEY_TOKEN
printf 'MONEY_TOKEN=%s\n' "$NEW" > ~/Library/Scripts/dora-money-token.txt
```
換完記得回捷徑把標頭裡那串也改掉。

## iPhone 捷徑怎麼建

1. 打開**捷徑** App → 右上角 **＋**
2. 加入動作 **「要求輸入」**
   - 輸入類型：文字
   - 提示：`花了多少？`
3. 加入動作 **「取得 URL 內容」**（Get Contents of URL）
   - 網址：`https://dora-line-secretary.zhuer0323.workers.dev/money`
   - 點「顯示更多」展開：
     - 方法：**POST**
     - 標頭：新增一列，鍵 `x-dora-token`，值貼上那串密碼
     - 請求本文：**JSON**，新增一個欄位，鍵 `text`，值選 **「提供的輸入」**
4. 加入動作 **「顯示通知」**，內容選上一步的結果
5. 右上角改名叫 **記一筆** → 完成

### 放到隨手可按的地方（挑你順手的）
- **鎖定畫面**：長按鎖定畫面 → 自訂 → 加小工具 → 捷徑 → 選「記一筆」
- **控制中心**：設定 → 控制中心 → 加入「捷徑」
- **對 Siri 說**：「嘿 Siri，記一筆」（它會問你花多少，可以直接用講的）
- **主畫面**：捷徑 App 裡長按 → 加入主畫面

## 可以怎麼講

| 你打 | 記成 |
|:--|:--|
| `120 午餐` | 8/19 飲食 NT$120，備註「午餐」 |
| `午餐 120` | 一樣（金額放前放後都可以） |
| `昨天 320 高鐵` | 8/18 交通 NT$320 |
| `8/17 680 電影` | 8/17 娛樂 NT$680 |
| `3天前 450 看醫生` | 8/16 醫療 NT$450 |
| `1,250 全聯` | 日用 NT$1,250（有逗號沒關係） |
| `+6000 接案` | **收入** NT$6,000 |
| `收入 48000 薪水` | 收入 NT$48,000 |
| `500` | 其他 NT$500（沒講是什麼就丟其他） |
| `午餐`（沒金額） | 擋下來，回你「沒看到金額」 |

回覆長這樣：

```
✅ 記好了 NT$320　交通（高鐵）
日期：8/18
這個月還能花 NT$765
```

（最後一行要設好每月預算才會出現）

## 分類怎麼判斷的

1. 你直接講分類名（「交通 320」）→ 就用那個
2. 講法對照表（午餐→飲食、加油→交通、全聯→日用、看醫生→醫療、禮金→人情⋯）
3. 都對不到 → **其他**

**不會自己長出新分類**（跟 LINE 排任務同一個原則，免得隨手打字生出一堆怪分類）。
要加分類到記帳 App 的設定頁加，接線生會讀你設定的清單。
講法對照表寫在 `line-secretary/src/money.js` 的 `ALIAS`，想加詞就加在那裡再 deploy。

## LINE 也能記帳

同一套東西，在 LINE 打**開頭有記帳字眼**的句子就會記成帳而不是任務：

- `記帳 120 午餐`
- `花了 320 高鐵`
- `$95 早餐`
- `+6000 接案`

沒有這些開頭的一律照舊當任務排進工作台，所以 `8/20 漁三 結案報表` 不會被誤認成花了 8 塊。

## 測試不想弄髒帳本

網址後面加 `?dry=1` 就只回結果、不寫進去：

```bash
curl -X POST "https://dora-line-secretary.zhuer0323.workers.dev/money?dry=1" \
  -H "x-dora-token: $(sed 's/.*=//' ~/Library/Scripts/dora-money-token.txt)" \
  -d '{"text":"昨天 320 高鐵"}'
```

## 出問題的時候

| 狀況 | 原因 | 怎麼辦 |
|:--|:--|:--|
| 捷徑回「密碼不對」 | 標頭那串貼錯或有多餘空白 | 重貼一次，注意不要把換行也複製進去 |
| 回「沒看到金額」 | 整句沒有數字 | 一定要有金額 |
| 分類老是跑到「其他」 | 對照表沒有那個詞 | 在 `money.js` 的 `ALIAS` 加詞，再 `npx wrangler deploy` |
| 記了但 App 看不到 | App 沒重新整理 | 下拉重整；還是沒有就檢查 Firebase 規則有沒有貼 |
| 日期跑掉 | Worker 跑在 UTC | 程式已經一律加 8 小時算台灣時間，不該發生；真的發生回報 |
