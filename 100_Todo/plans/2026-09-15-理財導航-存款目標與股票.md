## 你要做的事（一句話版）

存款銀行可以設目標和期限，系統自動算每個月該存多少。股票帳戶填持股後，每天收盤會自動更新市值和賺賠。定期定額設定一次，之後每個月到了扣款日，雲端會自己記帳並估算買到幾股，有空再改成對帳單上的實際股數就好。

## 背景和動機

- 第一批和四大項改版上線之後，帳戶頁的「存款」組只看得到餘額，看不出離目標還差多少。「股票」組目前是照轉進去的金額算，跟實際市值對不起來
- 定期定額每個月都會加碼，每次自己算均價、改股數很麻煩，所以要自動記
- 選了「雲端每天自己記」，不選「打開 App 時補記」。原因：LINE、手機捷徑記帳都不用打開 App；雲端自己跑的話不靠 Mac、不靠打開 App，記帳 App、「朱兒的獨自升級」看到的數字會一致

## 已經決定的事

| 項目 | 決定 |
|:--|:--|
| 存款目標 | **一個存款銀行一個目標**。帳戶餘額就是進度，永遠跟銀行對得起來 |
| 目標期限 | 選填。有填才算「每個月該存多少」 |
| 分配頁連動 | 儲蓄投資那組：有期限的存款銀行帶「這個月該存多少」；股票帳戶帶這個月定期定額的合計 |
| 總覽「存錢目標」 | 一律看分配排的儲蓄投資金額，設定裡的「存錢目標」欄位拿掉（舊數字留在資料裡不刪，沒排分配的舊月份照舊讀它） |
| 股票範圍 | 只做台股：上市、上櫃、ETF，零股就填實際股數 |
| 股票帳戶餘額 | ＝持股總市值，算進淨資產 |
| 定期定額 | 填一次：哪一檔、每月幾號、扣多少、從哪個帳戶扣、從哪個月開始。**雲端每天自己記**，股數用成交日收盤價估算，標「估」，點進去可改成實際 |
| 股價來源 | 證交所（上市）、櫃買中心（上櫃），免費公開資料。**2026-09-15 實測：兩邊都查得到「某一天」的收盤價**，隔幾天補記也拿得到扣款日的價格 |
| 抓不到價格 | 顯示最後一次抓到的價格和日期，不會變成 0 |
| 連動 | 「朱兒的獨自升級」年度目標裡的淨資產、帳戶餘額，一起改成照市值算 |

## 具體步驟

### Step 1：動工前備份，確認現有股票帳戶
- 做什麼：
  - 雲端記帳資料整包下載，存到 `~/Library/Scripts/dora-money-backup-20260915-時間.json`（不進版控）
  - 看現在有沒有股票帳戶、裡面有沒有起始餘額或轉帳。有的話，改版後那個帳戶會出現提示「先填目前持股，餘額才會改用市值」；**還沒填持股之前，照舊用轉進去的金額算**，數字不會突然變 0
- 產出：備份檔，並知道有沒有舊股票帳戶要過渡
- 注意：備份檔跟檢查結果都不寫進公開文件

### Step 2：存款目標
- 做什麼：
  - 點開存款銀行的帳戶視窗，多兩格：**目標金額**、**完成月份**（選填）
  - 帳戶頁存款組，每個有目標的帳戶底下多一條進度條：「已存 $X ／ 目標 $Y，達成 Z%」
  - 有期限時第二行小字：
    - 還沒達成：「這個月該存 $A，已經存了 $B」（還差的部分標出來）
    - 達成了：「達成目標了」，不再算建議
    - 過了期限還沒達成：「過了期限，還差 $C」
  - **這個月該存多少** ＝（目標 − 上個月底的餘額）÷ 從這個月到完成月份還有幾個月（兩頭都算），無條件進位到百位，最少 0。這樣算，同一個月內數字不會因為今天存了一筆就跳來跳去
  - 分配頁 ③ 儲蓄投資：這個月還沒排分配時，有期限的存款銀行預算框直接帶「這個月該存多少」（跟預存資金帶建議值同一種做法）
  - 設定裡的「存錢目標」欄位拿掉；總覽的存錢目標改看分配的儲蓄投資金額，沒排分配的月份照舊讀舊數字
- 產出：每個存錢帳戶看得到離目標多遠，排分配時自動帶這個月該存多少
- 注意：進度只看帳戶餘額。從存款銀行把錢轉出去，進度會跟著倒退，這是對的

### Step 3：雲端小程式：先確認抓得到，再做股價查詢與每天更新
- 做什麼：
  - **第一件事**：從雲端小程式實際打一次證交所和櫃買中心。在本機測是通的，但雲端主機在國外，政府網站有可能擋國外連線。**擋住的話先停下來回報**，改用下面「可能遇到的風險」寫的備案
  - 新增「查一檔股票」：網頁輸入代號時呼叫，回傳名稱、上市或上櫃、最近收盤價與日期。只回公開的股價資料，不碰任何帳務資料；只允許記帳網頁的網址來問
  - 新增**每天定時執行**（週一到週五，台灣時間 15:30、18:00、21:00 各一次；收盤資料什麼時候更新不一定，所以跑三次，已經拿到當天價格的後面兩次就跳過）：
    - 找出所有持股與定期定額用到的代號，一檔一檔查，把最新收盤價寫進雲端（名稱、價格、日期）
    - 一檔一檔查、不下載整份全市場檔案：櫃買那份有 4MB，免費方案每次執行的運算時間很短，整份讀會超時
- 產出：網頁不用自己去抓股價，打開就讀雲端存好的價格
- 注意：部署前先在本機模擬定時觸發跑過一次；這台 Mac 已經登入過雲端小程式，可以直接部署

### Step 4：雲端小程式：定期定額自動記帳
- 做什麼：每天定時執行時，接在更新股價後面：
  - 看每一組定期定額，從開始月份到這個月，哪一期**成交日已經到了、還沒記、也沒被她刪掉**
  - 成交日＝每月設定的那一天；那天沒開盤（假日、颱風假）就往後找第一個有開盤的日子
  - 拿到成交日收盤價才記，還沒有就等下一次執行
  - 一次記兩筆，用同一個固定編號（哪一組定期定額＋哪個月），兩台裝置、多次執行都只會有一筆：
    1. **轉帳**：從扣款帳戶轉到股票帳戶，金額＝扣款金額，日期＝成交日，備註「定期定額・名稱」
    2. **買進紀錄**：股數＝扣款金額 ÷ 成交日收盤價，無條件捨去到整股，成本＝扣款金額（含手續費），標「估」
  - 每次最多補 3 個月，避免設定打錯開始月份時一口氣長出一大堆帳
  - 她在網頁刪掉某一期（例如那個月暫停扣款），留一個「這期跳過」的記號，雲端就不會再補回來
- 產出：每個月不用做任何事，銀行餘額、股票股數、均價都會自己更新
- 注意：估算的股數跟券商對帳單會差一點（成交價不是收盤價、手續費折扣不同），所以一定標「估」，讓她知道哪幾筆還沒對過

### Step 5：網頁：股票帳戶的持股畫面
- 做什麼：點股票帳戶，打開持股畫面：
  - 最上面：總市值、總賺賠、報酬率、「價格日期 9/12」（舉例）
  - 每一檔一行：名稱＋代號、股數、均價、收盤價、市值、賺賠（賺綠賠紅，另外加正負號，色弱也分得出來）
  - 點某一檔，展開每一筆買進紀錄：日期、股數、金額、「估」標籤。點一筆可改成實際股數與金額，改完「估」拿掉
  - 「＋ 目前持股」：填代號（自動帶名稱）、股數、總成本或均價二選一。這是給**已經持有的部分**用的，不會記轉帳
  - 「＋ 定期定額」：填代號、每月幾號、扣多少、從哪個帳戶扣、從哪個月開始（預設下一次扣款的那個月，不會回頭補過去的月份）。之後可以改金額、改日期、暫停或刪除
  - 刪一筆買進紀錄時，連同那一期的轉帳一起拿掉，並留「這期跳過」記號
  - 明細裡定期定額的轉帳，點開顯示「這筆是定期定額自動記的，要改請到持股畫面」，避免兩邊改到不一致
  - 帳戶視窗的「校正餘額」股票帳戶不顯示，餘額一律看市值
  - 帳戶頁股票組原本那行「第二批改成照持股市值自動更新」的提示拿掉
- 產出：打開帳戶頁就看得到股票現在值多少、賺多少，每一筆買進都查得到
- 注意：畫面在 375px 手機寬度要能完整看到數字，不能擠到換行錯位；欄位太多時手機版把「均價、收盤價」收成第二行小字

### Step 6：「朱兒的獨自升級」數字對齊
- 做什麼：
  - 年度目標讀理財資料時，多讀持股與價格
  - 抄過去的帳戶餘額算法改成：股票帳戶有持股就照市值算，還沒填持股照舊（跟記帳網頁同一條規則）
  - 淨資產、指定帳戶的年度目標，數字要跟記帳網頁帳戶頁一模一樣
- 產出：兩個網頁講的淨資產一致
- 注意：程式註解裡原本寫「理財導航第二批股票照市值算上線時一定要改」，改完把這句更新成已同步

### Step 7：測試、上線、更新文件
- 做什麼：
  - **網頁離線自動測試**（擋掉雲端、寫入只進本機），至少涵蓋：
    1. 存款目標：進度條、這個月該存多少、達成、過期、分配頁帶建議值
    2. 總覽存錢目標改看分配、沒排分配的舊月份照舊
    3. 持股：新增目前持股、市值與賺賠、改實際股數後「估」消失、刪一筆連轉帳一起拿掉
    4. 股票帳戶沒填持股時照舊算、填了改市值；淨資產跟著變
    5. 價格讀不到時顯示最後一次的價格與日期
    6. 分配頁股票帳戶帶這個月定期定額合計
    7. 手機 375px、電腦側欄版面正常；記一筆頁不受影響（儲存按鈕仍在一個畫面內）
  - **雲端小程式測試**（假資料，不動真的雲端）：

    2. 同一期跑兩次只記一筆

    5. 一次最多補 3 個月

  - 「朱兒的獨自升級」：用本機測試資料確認淨資產跟記帳網頁一致
  - 快取版本號 `dora-money-v4` 改 `v5`
  - 部署雲端小程式、push 網頁，用真的網址打開再看一次
  - 更新 CLAUDE.md（記帳 App、朱兒的獨自升級兩段）、memory、第一批計劃書狀態列（第二批改指向這份）
- 產出：第二批上線，文件跟程式一致
- 注意：上線後請朱兒實際建一組定期定額和目前持股，等到下一次扣款日看雲端有沒有記進來，對過對帳單再算驗收

## 不包含在這次的範圍

- 賣出股票的紀錄與已實現賺賠（真的賣了，先手動改持股或刪紀錄；之後有需要再加）
- 配息、除權息自動入帳
- 美股與其他海外市場、基金（非 ETF）、定存單
- 盤中即時股價（只看收盤價）
- 股價漲跌或定期定額記好了的 LINE 推播
- 一個存款帳戶放好幾個目標
- 第三批：需要／想要標記、月底診斷

## 可能遇到的風險

- **雲端主機連不到證交所或櫃買中心**（政府網站擋國外連線）：Step 3 第一件事就測。擋住的話，備案是改用證交所的開放資料平台（本機測過會通，但只給最新一天、沒有歷史價格），雲端每天把價格存一份到雲端，補記時就用存下來的那天價格。這樣如果某天沒存到，那一期會改用之後最近一天的價格估，標「估」讓她對
- **收盤資料更新時間不固定**：一天跑三次，而且沒拿到價格就不記，隔天自己補
- **估算股數跟對帳單有差**：一律標「估」，點進去改成實際的；成本用實際扣款金額，所以均價偏差很小
- **資料來源改版、查不到**：顯示最後一次的價格和日期，不會變 0；只要改雲端小程式那一段，網頁不用動
- **定期定額設錯開始月份，一口氣長出很多帳**：開始月份預設是下一次扣款的月份，而且一次最多補 3 個月；刪掉的那期會留記號不會再長回來
- **舊的股票帳戶數字突然變了**：沒填持股之前照舊算，填了才改市值
- **兩個網頁的淨資產對不起來**：Step 6 專門處理，測試時兩邊逐一比對
