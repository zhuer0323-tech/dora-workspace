## 唯一要做的事：加規則

1. 開 <https://console.firebase.google.com/>，選專案 **busan-trip-2026-201f8**
2. 左邊選單 **Realtime Database** → 上方分頁 **規則（Rules）**
3. 整段換成下面這份 → 按 **發布（Publish）**

```json
{
  "rules": {
    "busan2026": {
      ".read": true,
      ".write": true
    },
    "meetings": {
      ".read": true,
      ".write": true
    },
    "connieScripts": {
      ".read": true,
      ".write": true
    },
    "ws_k7m2q9xr4t": {
      ".read": "auth != null && auth.token.email === 'zhuer0323@gmail.com'",
      ".write": "auth != null && auth.token.email === 'zhuer0323@gmail.com'"
    },
    "hy_social_r7n3k8": {
      ".read": "auth != null && auth.token.email === 'zhuer0323@gmail.com'",
      ".write": "auth != null && auth.token.email === 'zhuer0323@gmail.com'"
    }
  }
}
```

> 只有最後那段 `hy_social_r7n3k8` 是新的，前面四段是原本就有的，不要刪。

4. 回網頁重新整理 → 按「用 Google 登入」→ 右上角變綠點「雲端已同步」就成功了

## 第一次登入會發生什麼

雲端是空的，網頁會自動把 **9 月那 9 篇**寫上去。
之後你在網頁上改的每一個字都會存回雲端，換手機打開也看得到。

這個動作只會發生一次。第二次以後打開，讀的都是雲端最新版。
