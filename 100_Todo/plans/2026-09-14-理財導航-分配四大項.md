## 你要做的事（一句話版）

分配頁的大標題從「固定／存錢／生活費」三組，換成**固定支出／變動支出／預存資金／儲蓄投資**四大項，每一行預算跟實際並排；保險、稅金這種幾個月才繳一次的，每個月先存、繳的時候扣；分期付款會自己算第幾期、繳完自動消失。

## 背景和動機

- 第一批上線後，朱兒實際排預算時發現三組分法不夠用：
  - 保險、稅金這種**幾個月才繳一次**的，放固定支出會變成「繳的那個月爆掉、其他月份 0」，看不出到底有沒有存夠
  - **分期付款**要知道還剩幾期、每期多少，現在只能自己記在腦子裡
  - 預算跟實際花費沒有並排，要來回比對
- 記一筆的分類大致照舊（飲食、交通、日用…），**只多一個「預存資金」**

## 已經決定的事

| 項目 | 決定 |
|:--|:--|
| 四大項（照這個順序排） | 固定支出（含分期付款）／變動支出／預存資金／儲蓄投資 |
| 每一行 | 名字、預算（可以改）、實際（自動算），超過預算標紅；每一大項標題列顯示預算小計與實際小計 |
| 變動支出 | 就是原本「生活費」那九類：飲食、交通、日用、娛樂、醫療、人情、治裝、學習、其他 |
| 儲蓄投資 | 原本「存錢」那組，加上股票帳戶；實際＝這個月轉進去多少 |
| 預存資金 | 每月先存、繳時扣。記一筆多一個「預存資金」分類，選了出現細項（保險、稅金…） |
| 分期付款 | 放在固定支出裡。填「從哪個月開始、共幾期、每期多少」，系統算期數；每月繳款還是自己記一筆 |
| 「還能花多少」 | 記一筆頂端、總覽、LINE 回覆三處，一律看**變動支出**的預算 |
| 名字鎖住 | 「固定支出」「預存資金」這兩類名字不能改、不能刪（圖表、分配、LINE 都靠名字認） |
| 雲端資料 | 沿用原本位置，舊帳、9 月已經排的分配都保留，權限規則不用改 |

## 具體步驟

### Step 1：動工前備份
- 做什麼：把雲端的記帳資料整包下載，存到 `~/Library/Scripts/dora-money-backup-20260914-時間.json`（不進版控，倉庫是公開的）
- 產出：一份出事可以還原的備份
- 注意：備份完先看一下 9 月的分配長什麼樣，後面 Step 3 要確認改版後打開還是一樣的數字

### Step 2：記一筆多一個「預存資金」分類
- 做什麼：
  - 分類清單在「固定支出」後面自動插入「預存資金」，她已經改過分類清單也照插（這是系統分類，跟一般分類不同）
  - 名字鎖住、不能刪，改名與刪除時跳提示，跟「固定支出」一樣
  - 配一個新顏色，跟原本十色一起跑色盲檢查（`dataviz` skill 的驗證器），全部配對過關才用
  - 排版：優先改成一排六個，「固定支出」「預存資金」按鈕上只顯示「固定」「預存」，十一類剛好兩排。她自己加的分類名字超過兩個字時，退回一排四個、三排
  - 選到「預存資金」時，下面出現細項那一排（保險、稅金…，名字來自 Step 4 設定的預存項目），跟固定支出細項同一種樣式
  - 明細顯示「預存資金・保險」；點開改帳視窗，分類選預存資金時可以選細項
  - 總覽的「每天花多少」柱狀圖，**跟固定支出一樣不算預存資金**（一次繳兩萬會把圖壓扁）；「固定 vs 可以控制」那條分割條，改成「固定與預存 vs 可以控制」
- 產出：繳保險時記一筆「預存資金・保險」，不會被算成亂花錢
- 注意：記一筆整頁一定要塞進一個手機畫面。量「儲存」按鈕底部有沒有超過分頁列頂端，**分別在 375px 與 360px 寬、有細項那排出現時**各量一次

### Step 3：分配頁換成四大項，預算實際並排
- 做什麼：
  - ③ 那一塊的三組換成四大項，順序：固定支出 → 變動支出 → 預存資金 → 儲蓄投資
  - 每一行：名字（可點下去改名，鎖住的除外）、第二行小字「上月實際 X」、右邊預算框，框下面小字「實際 Y」，實際超過預算標紅
  - 每一大項標題列：「預算 $A　實際 $B」
  - 固定支出：原本的細項＋「其他固定支出（不分細項）」＋ Step 5 的分期付款
  - 儲蓄投資：每個存款銀行、每個股票帳戶各一行，加「存起來（不指定帳戶）」；實際＝本月轉進該帳戶的金額，「不指定帳戶」那行實際顯示「—」
  - 待分配 ＝ 收入 −（固定支出 ＋ 變動支出 ＋ 預存資金 ＋ 儲蓄投資）
  - ② 建議可存 ＝ 收入 − 上月固定支出實際 − 本月預存建議合計 − 上月變動支出實際，四捨五入到百位；說明文字照這個算法改寫
  - 「沿用上個月」：預存資金那組一起抄；分期付款不照抄，改用這個月還在繳的分期
- 產出：一頁看完四大項各排了多少、實際花了多少
- 注意：打字時不重畫整頁（原本 `allocBusy()` 的做法照舊），雲端同步才不會把打到一半的數字洗掉；9 月已經排好的分配打開後，固定、存錢、生活費的數字要分別出現在固定支出、儲蓄投資、變動支出，總額不變

### Step 4：預存資金的追蹤
- 做什麼：
  - 預存資金那組底下「＋ 新增預存項目」，跳一個小視窗填：名稱、一次繳多少、幾個月繳一次（1～24）、下次哪個月繳、目前已經存了多少（沒有就填 0）
  - 每一行右邊有「設定」可以回來改，改名會一起更新已經記過的帳與各月分配
  - **已存多少** ＝ 設定時填的已存 ＋ 從設定那個月起，每個月分配給它的預算（當月一到就算存進去）− 從設定那個月起，記在這個項目的繳費
  - 這是帳面上幫你記著，**不會真的搬錢**
  - **建議每月存多少** ＝（一次繳多少 − 上個月為止已存）÷ 從這個月到繳費月還有幾個月（兩頭都算），無條件進位到百位，最少 0。這個月還沒填預算時，預算框直接帶建議值
  - 行內第二行顯示：「已存 $X ／ 要繳 $Y　還差 N 個月（M 月繳）」
    - 繳費月當月：有記繳費顯示「這期繳好了」，沒記顯示「這個月要繳，還沒記」
    - 已存變負的（繳的比存的多）：顯示「預存不夠，這次墊了 $Z」
  - 繳費月過了之後，「下次哪個月繳」自動往後推一個週期
- 產出：例如一年繳一次的保險，分配頁每個月會寫「已存多少／要繳多少，還差幾個月」，繳的那個月不會爆預算
- 注意：預存資金的實際繳費**不算進「還能花多少」**，也不算那個月超支

### Step 5：分期付款
- 做什麼：
  - 固定支出那組底下「＋ 新增分期」，小視窗填：名稱（例如 iPhone）、從哪個月開始繳、共幾期、每期多少
  - 從開始月份算起、還沒繳完的月份，分配頁固定支出自動多一行，預算自動帶每期金額（可以改），第二行寫「第 3 期／共 12 期，剩 9 期」
  - 繳完的下個月起，分配頁與記一筆都不再出現；舊帳的明細照樣顯示名字
  - 記一筆選固定支出時，細項那排會出現還在繳的分期；每月實際繳款自己記一筆「固定支出・iPhone」
  - 這個月還沒記那一期的，實際欄顯示「還沒記」（淡色，不標紅）
  - 分期可以改（例如提前還清就把期數改少）、可以刪（有帳在用的，刪了只拿掉設定，舊帳保留）
- 產出：分期付款不用記在腦子裡，一眼看到還剩幾期
- 注意：一個月的分配存下來時，分期金額跟著存進那個月，之後改分期設定不會回頭改掉已經排好的月份

### Step 6：總覽與 LINE 記帳對齊
- 做什麼：
  - 記一筆頂端預算條、總覽「還能花多少」：看變動支出的預算，扣掉的只有變動支出的花費（固定支出、預存資金都不扣）

    - 講法對照表加上兩個字以上的稅名（牌照稅、燃料稅、房屋稅、地價稅、所得稅）→ 預存資金；**不放一個字的「稅」**

  - 部署：這台 Mac 的 wrangler 還沒登入，要請朱兒在對話框打 `! npx wrangler login` 登入一次，登入後由 Claude 跑部署。**昨天第一批的 LINE 新回覆也還沒部署，這次一起上**

- 注意：部署前先用 `?dry=1` 試算，只回結果不寫入

## 預計成果

## 不包含在這次的範圍

- 預存資金真的把錢搬到另一個帳戶（這次只在帳面上記著；要真的搬，照舊用「存入」轉到存款銀行）
- 分期付款每月自動記帳（照你的選擇，自己記）
- 分期的利息、手續費計算
- 存款目標、股票自動抓價（第二批）；需要／想要、月底診斷（第三批）
- 手機捷徑密碼對不上的問題（本機 `dora-money-token.txt` 跟線上不一致，另外處理）

## 可能遇到的風險

- **記一筆從十類變十一類塞不下一個畫面**：優先一排六個＋短標籤，Step 2 在兩種手機寬度都量過才上線
- **9 月已排的分配數字跑掉**：Step 1 先備份、Step 3 逐組對數字，出事可以用備份與 git 退回
- **預存已存的數字跟心裡想的對不上**（例如之前某個月沒排分配）：每一行的算法攤開寫，設定視窗可以直接改「目前已經存了多少」重新起算
- **LINE 小秘書沒辦法部署**：卡在 wrangler 登入，要朱兒登入一次；沒部署前 LINE 記「保險」會落到舊分類，網頁本身不受影響
- **手機一直開到舊畫面**：換快取版本號；真的卡住請她把 App 關掉重開

## 給執行時的技術備註

- 原始檔：`100_Todo/projects/money/index.html`、`money/sw.js`（`CACHE` → `dora-money-v3`）、`line-secretary/src/money.js`
- 新常數：`PRE_CAT = '預存資金'`，跟 `FIXED_CAT` 同等對待（`renameCat`／`deleteCat` 擋下、柱狀圖 filter、分割條）
- `CATS_VERSION` 加一，`migrateCats()` 新版一律把 `PRE_CAT` 插在 `FIXED_CAT` 後面（不受「只在沒改過時才動」限制）；`DEF_OUT` 兩處同步
- `CAT_COLORS` 加 `預存資金`，跑 `validate_palette.js`
- `.cats` grid 預設 `repeat(6,1fr)`，按鈕顯示短標籤；`settings.cats` 裡有兩個字以上（排除兩個系統分類）就加 class 退回 `repeat(4,1fr)`
- settings 新欄位：
  - `preItems: [{id, name, amt, every, next:'YYYY-MM', open, openYm:'YYYY-MM'}]`
  - `inst: [{id, name, start:'YYYY-MM', n, amt}]`
- 帳目：預存繳費 `{cat:'預存資金', sub:<preItem.name>}`；分期繳款 `{cat:'固定支出', sub:<inst.name>}`
- alloc 新欄位：`pre: [{k:name, v}]`；分期沿用 `fix`（`k` 用分期名稱），`blankAlloc()`／`copyPrevAlloc()` 依 `inst` 帶入當月還在繳的、拿掉已繳完的
- `totalsOf()` 回傳改成 `{inc, fix, vary, pre, save, used, left, …}`，`life` 保留成 `vary` 的別名，`budgetOf()`／`spentFor()` 只扣變動支出（排除 `FIXED_CAT`、`PRE_CAT`）
- `saveRows()` 加 `type==='stock'` 的帳戶
- 已存計算（實作是 `preInfo(p, ym, a)`）：上個月底已存 ＝ `open` ＋ Σ `alloc[m].pre[name]`（`openYm ≤ m < ym`）− Σ 帳目（`cat=PRE_CAT, sub=name`，同區間）；當月已存再加這個月預算、減這個月繳費。`next` 若 `< ym` 就往後加 `every` 直到 `≥ ym`，**每次用算的，不寫回 settings**（寫回要多一次雲端寫入，算的結果一樣）
- 「這期繳好了」＝這個月有繳，或上一次繳費月之後、這個月之前提早繳過；提早繳過時建議值改算下一期
- 記一筆鍵盤鍵高從 52px 壓到 48px，375×812 才塞得下（改版前就超出 17px）。360×740 改版前超出 89px、現在 67px，要重新設計版面，不在這次範圍
- 分期期數：`k = monthDiff(start, ym) + 1`，`1 ≤ k ≤ n` 才顯示
- `money.js`：`allocInfo()` 的 life 排除 `PRE_CAT`、used 加 `pre`；細項比對擴充成 `preItems` 名稱→`PRE_CAT`、`inst` 名稱（當月還在繳）→`FIXED_CAT`，都是最長的優先；`ALIAS` 加稅名到 `預存資金`
- 測試：Playwright 帶 `executablePath` 指到 `chromium-1234`（見 CLAUDE.md「朱兒的獨自升級」測試段）；本機 `python3 -m http.server 8765 --bind 127.0.0.1`
