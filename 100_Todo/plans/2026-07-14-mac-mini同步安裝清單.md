# Mac mini 同步安裝清單

> 2026-07-14 產出。目標：讓第二台 Mac mini 與現有 MacBook 共用同一套 Claude Code 環境。
> 基礎架構見 `000_Agent/MIGRATION.md`（情境 1），本清單為其補完版。

## 同步架構總覽

| 內容 | 存放處 | 同步方式 |
|:--|:--|:--|
| 工作區（專案、草稿、CLAUDE.md） | GitHub `zhuer0323-tech/dora-workspace` | git pull / push |
| settings.json、skills、hooks | OneDrive `Dora-Agent/` | OneDrive 自動同步 |
| MCP 設定（`~/.claude.json`，含 Firecrawl key） | 各機本地 | 手動搬一次 |
| Claude 自動記憶（`~/.claude/projects/`） | 各機本地 | 手動搬一次（可選） |
| 早報排程（LaunchAgent） | 各機本地 | **只裝一台**，避免重複推播 |

## 新機器安裝步驟

### 1. 基礎環境
- [ ] 登入同一個 Microsoft 帳號（`Janice52198@outlook.com`，2026-07-14 起啟用），等 OneDrive 同步完成
  - 驗證：`ls ~/Library/CloudStorage/OneDrive-個人/Dora-Agent/` 看得到 `000_Agent`
- [ ] 安裝 cmux 終端機：https://cmux.com 下載 dmg，拖進應用程式（免設定，裝完即用）
- [ ] 安裝 Claude Code，執行 `claude` 登入同一帳號（認證是每台獨立的）
- [ ] 安裝 nvm + Node.js v24（MCP 的 Firecrawl / Playwright 依賴）

### 2. Clone 工作區（路徑必須一模一樣）
```bash
git clone https://github.com/zhuer0323-tech/dora-workspace.git ~/Downloads/Dora專屬
```
路徑要是 `~/Downloads/Dora專屬`，否則 CLAUDE.md 路由表與專案記憶都會對不上。

### 3. 建立 symlinks
```bash
ln -sf "$HOME/Library/CloudStorage/OneDrive-個人/Dora-Agent/.claude/settings.json" \
       "$HOME/.claude/settings.json"
ln -sf "$HOME/Library/CloudStorage/OneDrive-個人/Dora-Agent/000_Agent/skills" \
       "$HOME/.claude/skills"
```

> **重要坑**：repo 裡的 `000_Agent` symlink 是絕對路徑 `/Users/angela/...`。
> 新 Mac mini 的使用者名稱如果**不是 angela**，clone 下來的 symlink 會斷掉，要重建：
> ```bash
> rm ~/Downloads/Dora專屬/000_Agent
> ln -s "$HOME/Library/CloudStorage/OneDrive-個人/Dora-Agent/000_Agent" \
>       ~/Downloads/Dora專屬/000_Agent
> ```
> （只影響本機，不要把重建後的 symlink commit 回去，除非兩台使用者名稱相同）

### 4. 搬 MCP 設定（MIGRATION.md 沒寫到的部分）
`~/.claude.json` 含 Firecrawl API key，**不在 OneDrive 也不在 git**：
- 用 AirDrop 把舊機的 `~/.claude.json` 傳過去，只複製其中 `mcpServers` 相關區塊到新機的 `~/.claude.json`
- 或在新機重新執行 `claude mcp add` 安裝 Firecrawl（key 到 firecrawl.dev 帳號取）與 Playwright
- 不要整份覆蓋：`~/.claude.json` 也存有各機自己的狀態

### 5. 搬 Claude 自動記憶（可選但建議）
讓新機的 Claude 也記得過去的專案脈絡：
```bash
# 舊機打包
cd ~/.claude/projects && zip -r ~/Desktop/dora-memory.zip "-Users-angela-Downloads-Dora--/memory"
# AirDrop 到新機後解壓到同路徑（使用者名稱不同時，資料夾名的 angela 要改成新使用者名）
```

### 6. 決定不裝的東西
- **早報 LaunchAgent**（`~/Library/Scripts/dora-morning-briefing.sh` + plist）：只留在常開機那台，兩台都裝會收到兩則早報
- **ffmpeg**：只有要跑 video-autopilot-kit 才需要（`~/.local/bin`，來源 ffmpeg.martin-riedl.de）

### 7. 驗收
- [ ] 跑體檢：`bash ~/Library/CloudStorage/OneDrive-個人/Dora-Agent/000_Agent/scripts/sync-health.sh`
- [ ] 在 `~/Downloads/Dora專屬` 開 `claude`，輸入 `/morning` 確認 skills 有載入
- [ ] 問 Claude「上次我們做到哪」，能答出近期專案代表記憶接上了

## 日常兩機協作習慣
- 開工前：`git pull`
- 收工後：「ok儲存」（commit + push）
- skills / settings 改動不用管，OneDrive 自動同步
- 換機工作前確認 OneDrive 圖示顯示已同步完成，避免改到舊版 skill
