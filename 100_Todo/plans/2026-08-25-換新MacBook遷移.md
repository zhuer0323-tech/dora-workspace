## 判斷：什麼才真的會遺失

四塊東西裡，兩塊新機自己會有：

| 內容 | 怎麼過去 |
|:--|:--|
| skills / settings / hooks | OneDrive 母體 `Dora-Agent/`，登入同帳號自動同步 |
| 工作區專案、草稿、客戶檔 | GitHub `dora-workspace`，clone 就有 |
| **憑證與腳本、排程、會議逐字稿、Claude 記憶、MCP key** | **只在本機，非搬不可** |

第三塊細項（總共 3.6MB）：
- `~/Library/Scripts/` — LINE token、Meta 系統使用者 token、Firebase 服務帳號金鑰、
  記帳 token、六支腳本。金鑰刻意不進版控（repo 是公開的）
- `100_Todo/meetings/` 15 場會議逐字稿 — `.gitignore` 擋著（含客戶機密）
- `.claude/settings.local.json` — 權限規則，`.gitignore` 擋著
- `~/.claude/projects/-Users-angela-Downloads-Dora--/memory/` 148KB — Claude 自動記憶
- 六個 `com.dora.*.plist` — 早報、廣告日報、快結束提醒、回報提醒、回報 runner、釜山 Pass
- `~/.claude.json` 裡該專案的 `mcpServers`（Firecrawl API key、Playwright）

## 做法

打包成 `~/Desktop/dora-migrate-20260825.zip`（1.4MB）走 AirDrop，
新機解壓跑 `install.sh` 一次到位。腳本已存進母體
`000_Agent/scripts/migration/`（含打包指令），下次換機直接用。

**路徑寫死是最大的坑**：六支腳本與六個 plist 全部寫死 `/Users/angela`
（`source dora.env`、`CLAUDE`、`WORKDIR`、plist 的 PATH 與 ProgramArguments）。
`install.sh` 會偵測新機使用者名稱，不同就整批 sed 改掉，plist 的 node 版本路徑也一併對到新機實際版本。

**排程只能有一台在跑**。install.sh 預設不裝排程，要等舊機跑完 `舊機收尾.sh`
（unload ＋ plist 改名 `.disabled`）之後，再回新機 `bash install.sh --schedule`。
兩台都開著的話早報跟廣告日報會一天收到兩份。
