## 你要做的事（一句話版）

在禾言社群規劃網頁上按一顆「複製這篇」，跟 Claude 說一聲，就拿到一份**在 Canva 裡可以直接改字**的六頁 IG 圖卡。

## 背景和動機

現在圖卡是用網頁排版檔在本機出成 PNG，是死圖——想改一個字就得回頭找 Claude 重出一次。
朱兒要的是最後落在 Canva 上、自己隨時能動的可編輯檔。

2026-08-17 實測（盾牌版匯入 Canva，設計檔 DAHShduaKOs）確認：
- 版面、顏色、logo、角落星星、卡片框線、文字位置**都正確**，文字可點進去改
- 三個走樣的地方：黑底白字的強調變成黑槓蓋住字、盾牌下緣弧形沒帶過去、字型換成 Canva 預設

## 已定案的決定

| 項目 | 決定 |
|:--|:--|
| 圖卡版型 | **柔和版**（無框大圓角）。粗框版、盾牌版不再維護 |
| 標題強調樣式 | **黃底深字**（原本黑底白字，匯入 Canva 會變黑槓） |
| 最終產出 | Canva 可編輯設計檔，不是 PNG |
| 誰做濃縮 | Claude。六頁短句與示意圖依內容設計，不套固定規則 |
| 網頁要加的東西 | 只加一顆「複製這篇」按鈕，不在網頁上做圖 |

## 具體步驟

### Step 1：把柔和版改成正式模板
- 做什麼：以 `100_Todo/drafts/social-cards/柔和版_原始檔.html` 為底，把 `.hl`（標題強調）從黑底白字改成品牌黃底深字；同步改 `h1 .hl`、`h2 .hl` 與第 6 頁那個 inline style 的強調
- 產出：`100_Todo/projects/heyen-cards/index.html` 換成柔和版（取代現在的盾牌版）
- 注意：每張卡要保留 `data-document-role="page"` 與 `data-label`，這是 Canva 匯入認頁的依據

### Step 2：匯進 Canva 實測一次
- 做什麼：push 後等 GitHub Pages 更新，用 Canva 匯入公開網址，逐頁檢查
- 產出：一份確認過的 Canva 設計檔，以及一份「哪裡還會走樣」的清單
- 注意：重點看三件事——黃底強調字有沒有蓋住、大圓角有沒有變方角、六頁是不是都在

### Step 3：網頁加「複製這篇」按鈕
- 做什麼：在 `100_Todo/projects/heyen-social/index.html` 每篇的「⋯」選單裡加一個「複製這篇給 Claude」，複製內容為：日期、類型、標題、貼文主題、完整文案
- 產出：按一下就整篇進剪貼簿，貼給 Claude 即可
- 注意：不要影響現有的「複製文案」鈕；月曆與圖文表兩個地方的選單都要加

### Step 4：更新「禾言圖文」skill
- 做什麼：把 skill 的流程改成——讀規劃表那篇 → 給朱兒確認議題與文案 → 依內容設計六頁（示意圖依內容選型：對比卡／漏斗／編號列表／完整漏斗）→ 套柔和版模板產生 HTML → 放到公開頁 → 匯入 Canva → 回連結
- 產出：`~/.claude/skills/禾言圖文/SKILL.md` 更新
- 注意：把 Canva 的已知限制寫進 skill（字型帶不過去、要朱兒自己上傳源柔 ttf 到 Canva 一次），下次接手不用重踩

### Step 5：拿一篇真的貼文跑完整流程

- 產出：一份可交件的 Canva 圖卡，以及流程有沒有卡點的紀錄
- 注意：這步是驗收，沒跑過不算完成

## 可能遇到的風險

- **字型帶不過去**：Canva 只認自己的字型庫，源柔體要朱兒自己下載 ttf 上傳 Canva（一次就好，之後每份設計都選得到）。在她上傳之前，Canva 裡看到的會是預設中文字
- **黃底強調字還是位移**：如果 Step 2 實測發現色塊仍蓋住字，退回「粗底線」版本（強調字下面畫粗黃線，沒有色塊就不會蓋到）
- **內容要公開才能匯入**：圖卡 HTML 得放在公開網址 Canva 才抓得到。禾言自家貼文本來就要發，可接受；但**客戶案例數據不要放進圖卡**
- **大圓角可能被 Canva 拉平**：若圓角走樣，改用整張背景圖片墊底、文字疊上去的做法（文字仍可編輯，只是背景不能改）
